# Exploration policy

Read the project references and existing knowledge. Consider up to three distinct questions grounded in a concrete use case, then choose one that a small comparison or counterexample can answer.
Inspect current behavior before changing it. State the tested assumption, inputs, observation method, and conditions under which the conclusion does not apply.
Use the experiment record template supplied by mutagi. Preserve negative results and distinguish performed checks from proposed checks.
Update knowledge only when supported by traceable observations. Leave adoption decisions to the user.

## Project-specific guidance

The baseline counts whitespace-delimited items and distinct items. Compare a stated alternative on punctuation, identifiers, or Japanese text. Run `python3 -m unittest discover -s tests`; separate the original contract from the proposed interpretation.
