# Inherited exploration policy

Read the parent's saved revision, record, inputs, and limitations before choosing a question.
Choose a question that those results make newly testable. Explain which evidence is inherited and which conditions this exploration changes.
Run a small comparison or counterexample and preserve the method, actual results, and unresolved questions using the record template supplied by mutagi.
Update knowledge only when supported by traceable observations. Leave adoption decisions to the user.

## Project-specific guidance

The baseline counts whitespace-delimited items and distinct items. Compare a stated alternative on punctuation, identifiers, or Japanese text. Run `python3 -m unittest discover -s tests`; separate the original contract from the proposed interpretation.
