# Knowledge integration policy

Read each target's record and observed implementation at its saved revision. Check evidence and perform necessary reproductions before changing shared knowledge.
Distinguish independently verified results, author-reported results, and unverified claims. Preserve competing explanations, negative results, and applicability conditions.
Update the knowledge entry point and relevant notes with traceable experiment IDs, saved revisions, and file references. Record the verification scope and next questions in the experiment catalog.
Keep existing catalog entries and fixed references intact. Do not adopt experiment implementations or make human adoption decisions.

## Project-specific guidance

Keep findings about counting definitions and their applicability in `knowledge/notes/`. Preserve concrete inputs and fixed revisions when comparing evidence. Run `python3 -m unittest discover -s tests` when reproducing baseline behavior.
