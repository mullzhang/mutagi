# Runnable examples

[minimal-python](minimal-python/README.md) is a complete project using only Python's standard library.
It includes a small implementation, baseline tests, exploration policies, a reusable instruction, and round and series plans.
Copy it into a separate Git repository before running mutagi; running in this checkout would target the mutagi repository itself.

Install mutagi and authenticate the Codex CLI first. Choose a model available to your account and pass it through `--model`.
The sample plans omit the model so they can be used without editing their files.

The example also demonstrates previewing plans, constructing a round without JSON, and inspecting readable status.
