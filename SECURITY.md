# Security policy

Report suspected vulnerabilities privately using **Report a vulnerability** on the repository's [Security page](https://github.com/mullzhang/mutagi/security). Coordinate disclosure with the maintainer before publishing vulnerability details.

If private reporting is unavailable, open an issue asking for a private reporting channel without including vulnerability details, exploit code, or logs.

In a private report, include:

- The affected mutagi version or commit, operating system, and Codex CLI version.
- Minimal reproduction steps and the expected and observed behavior.
- The potential impact and any relevant logs with sensitive values removed.

Use dummy credentials and synthetic data in reproductions. Do not include live credentials or private project data in a report.
