# Experiment catalog

mutagi registers preserved explorations here with their saved revisions and record paths.
Read each record's evidence and limitations before deciding whether to adopt a result.

Use `mutagi harvest list` to search results and `mutagi harvest show <experiment-UUID>` to read a fixed record.
`mutagi harvest prepare <experiment-UUID> --purpose TEXT` prints a prompt for using selected results; add `--output FILE` to save it.
